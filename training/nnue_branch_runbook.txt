NAGATO NNUE BRANCH RUNBOOK (video-style iteration)

Format rules
- one branch = one feature slice
- one concise commit per slice
- always benchmark and test before merge
- merge only when measurable and clean

Branch naming
- experiment/nnue-p2-king-bucket-mapper
- experiment/nnue-p2-halfkp-transformer
- experiment/nnue-p2-accumulator-kbucket
- experiment/nnue-p2-weight-loader-v2
- experiment/nnue-p2-tests-bench

Next slice to implement

- done criteria:
  - benchmark command runs locally and in CI-friendly mode
  - output includes nps/eval-time for scalar path

Per-slice checklist
1) create branch from master
2) implement only the slice scope
3) run cargo test (targeted + full if fast)
4) run benchmark command and store output artifact
5) commit with concise message
6) push branch
7) merge after review

Command skeleton
- git checkout master
- git pull --ff-only origin master
- git checkout -b <slice-branch>
- cargo test
- <benchmark command>
- git add <files>
- git commit -m "feat: <small slice>"
- git push -u origin <slice-branch>
